# Estratégia de busca de catálogo

## Critérios
- SKU exato
- barcode exato
- prefixo do nome
- nome aproximado
- atributo/variante
- categoria e marca
- recentes do contexto

## Regras técnicas
- normalização de texto
- consulta assíncrona
- debounce
- limite de resultado
- cache de sessão
- paginação
- ordenação por relevância operacional

## Resposta mínima
- SKU
- nome curto
- variante
- saldo disponível
- preço principal
- unidade
- status
- localização principal
